JAMB Prep apps: UI design

Three products, one design language: student mobile (Android), student desktop and school desktop (Windows). Tokens, fonts, cards and buttons are the web app's (app/globals.css, Fredoka and Plus Jakarta Sans, embedded in this file). Flutter must reuse the same values.

Rules for all three

PlatformsMobile is for students only. It opens exactly like the web app (landing, sign in, onboarding). There is no "school or student" choice on mobile. The Windows app asks "School or Student" on first launch. School mode exists only there.
LogoThe real logo: graduation cap with the gold JAMB band underneath (components/brand/logo.tsx, labelled version), then "JAMB Prep". The logo is always at the top. Nothing sits before it.
NavigationMobile: bottom bar (Practice, Games, Leaderboard, Downloads, Profile). Desktop: a deep green sidebar with the logo at the top and the active item as a white pill (decided). No navigation appears during a practice session or on a setup screen. It shows again on results.
DownloadA round icon button, never the word and no file sizes. Ready shows a small check, an update a round refresh button, downloading a progress bar. A Downloads page in the navigation (school and student) manages everything.
CampaignsA banner at the bottom of Home, "Tap for details". It exists only while the admin page has an active campaign for that audience and date range.
MascotOptional. Nothing depends on it. When it arrives it sits beside the welcome text, never before the logo.
BackgroundA soft pattern of subject icons (books, atoms, flasks, maps) behind the page, under the cards. Asset: docs/assets/learning-pattern.svg. Cards stay solid white so reading is never harder.
